# Gobernanza

Roles: maintainers approve releases; module maintainers own interfaces/tests; data reviewers verify mappings/licences; methodology reviewers assess reproducibility. Material changes use RFCs with a 14-day comment period when practical. Decisions document alternatives and conflicts. Disputes escalate from discussion to an uninvolved maintainer panel. Funding cannot purchase methodology outcomes. Maintainers disclose relevant conflicts and recuse.
