# Contribuir

Open an issue/RFC for material changes. Fork, branch, install with the lockfile, add tests, run all checks, and sign commits with `Signed-off-by: Name <email>` (DCO). Data adapters must include official URLs, exact field mapping, licensing status, idempotency keys and sanitized fixtures. Indicators require formula, comparison population, minimum sample, limitations and record references. No accusations or personal data.
